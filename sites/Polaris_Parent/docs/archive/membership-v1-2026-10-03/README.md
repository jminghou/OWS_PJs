# 會員系統 v1 封存基準

封存日期：2026-10-03（Asia/Taipei）。

目的：保留舊會員系統的需求與實作，供全新會員系統設計及必要時還原參考。新版需求另行制定，舊版規格不自動視為新版需求。

## 封存範圍

- 舊會員需求規格。
- 本站前端原始碼（包含會員中心、登入、設定密碼、後台審核、導覽與當前首頁修改）。
- 本站會員及紫微 API、模型、設定、應用掛載、資料庫 migrations 與會員資料表初始化 SQL。
- 共用後端引擎及 platform-api、admin-app、ziwei-app 原始碼，以保留會員所依赖的平台功能。
- source/ 保存原始目錄結構；source-snapshot.zip 是同一份原始碼的壓縮副本。
- manifest.json 記錄各檔案相對於 monorepo 根目錄的路徑與 SHA-256。

Git 基準：9b99e9d96a6eb297ab058d30b95d4f86cfb281ca。封存是當下工作目錄的快照，包含尚未提交的首頁樣式修改。

## 不包含的內容

不包含正式或本機資料庫的會員資料、密碼、命盤、訂單與發券記錄；不包含 .env、服務金鑰、套件安裝目錄及部署環境。這是原始碼與規格封存，不是可直接部署的完整系統備份。

## 當前處置

此步驟沒有關閉入口、刪除會員、修改資料表或修改共用套件。重建期間的舊功能開關，以及舊資料保留／遷移方式，等待使用者決定。

還原時先比對所需檔案，按範圍逐一恢復；不要整批覆蓋共用套件或其他後續修改。資料库還原需要另備資料備份。
