## 2. 品牌核心：理解要回到親子之間

**既定｜來源：B §1–5、§17；P §1；A §2、§7。**

親紫之間以紫微斗數命盤作為理解工具，從父母理解自己、重新看見孩子開始，透過生活觀察、對話與修正，增加親子互相理解的可能。

它關心的是：明明在意彼此，卻反覆誤讀對方；明明靠得很近，仍覺得自己的感受與用意沒有人懂。品牌不把所有親子問題都歸因於不理解，也承認疲憊、資源、現實壓力與界線分歧的影響。

品牌希望促成的最小改變，是父母在一個熟悉的時刻暫緩判斷，多觀察一次、多聽一句，讓孩子的回應改變自己的理解。幼兒的行為與非語言反應同樣重要。

> 核心檢視問題：這段文字或這項設計，是否增加父母理解自己、重新看見孩子，並回到真實互動的可能？

### 內部公式與對外表達

原始內部公式是「恐懼是入口，孤獨是病，認得是藥」。它是策略比喻，不是診斷或療效主張，不直接當作首頁標語。

- **恐懼：**可辨認父母已有的擔心，也可以從好奇、欣賞、收藏與送禮切入。不得製造「不買就會害了孩子」的新恐懼。
- **孤獨：**用具體處境讓讀者自行辨認，不直接替讀者宣布「妳很孤獨」。
- **認得：**看見先前漏掉的感受、需要與差異，並容許修正；不是掌握孩子永遠不變的本質。

品牌承諾的是提供理解的條件與線索。購買、讀完、覺得很準，都不等於孩子已感到被理解。

## 3. 品牌生命觀與方法

**既定｜來源：B §4–6、§14、§17–18；P §1、§7。**

### 生命有自己的展開方式

孩子有自己的傾向、節奏與可能性。橡實、靈魂呼喚與生命紋理，是品牌用來描述這份獨特性的隱喻；不代表出生資料已證明他的固定本質。環境、經驗、關係與選擇都會參與人的發展。

同一種特質可以有不同面向。細緻可能帶來察覺，也可能在壓力中形成負擔。寫作要說清楚情境，不把所有困難美化成天賦，也不把責任或界線取消。

北極星代表定位；父母與孩子可以朝不同方向前進。Jermaine 的角色是「幫妳認星的人」，不成為需要依賴的北極星。

### 方法必須坦白，理解必須可修正

清楚說明使用紫微斗數，不將它包裝為經科學驗證的人格測驗、心理評估或診斷工具。方法頁應交代出生資料、排盤、判讀與敘事之間的過程；不將這個過程寫成證明人格的因果鏈。

**命盤提供可能線索 → 生活觀察與對話 → 依當事人經驗修正或放下解讀 → 嘗試回應 → 再看互動。**

孩子說「不是這樣」必須能改變理解。孩子未參與時，區分父母觀察、命盤詮釋與未知之處。理解不等於要求孩子服從、原諒或負責安撫父母。

AI 可以協助研究、整理、計算、初稿與排版；最終交付須保留人的閱讀、判斷與責任。對製作流程如實說明，不能虛構全手工，也不能只用「有人看過」代替可核對的流程。

## 4. 我們在對誰說話

**既定與受眾假設分開使用｜來源：B §7；A §1–9。**

核心溝通對象是已讀過不少教養內容、仍在某些日常時刻卡住，並重視內容深度與美感的父母。原始定位聚焦 30–45 歲母親與文藝型父母；這是溝通重心，不是服務資格或付費能力判斷。

| 讀者當下的需求 | 頁面應回答的問題 | 可用的信任線索 |
| --- | --- | --- |
| 想先了解自己或孩子 | 跟我家的哪個時刻有關？能多看見什麼？ | 具體場景、內容樣本、方法說明 |
| 想處理一個真實問題 | 這件事適合拿來談嗎？會怎麼談？ | 服務範圍、對話方式與限制 |
| 想收藏或送禮 | 留下什麼心意？對方願意收到嗎？ | 內頁與物件樣本、客製與資料流程 |
| 因興趣持續閱讀 | 這個觀點有深度嗎？容得下反例嗎？ | 完整論述、開放問題與生活連結 |

這些是需求參照，不是已驗證的市場分群。原始受眾資料主要來自熟人觀察，不可轉寫為真人見證、購買率或市場定論。對外不使用人物姓名、關係鏈、孩子細節或「高知理性媽媽」等內部分類。

## 5. 品牌人格與穩定聲音

**既定｜來源：B §10–12、§15；P §7；A §7。**

品牌人格是「父親 × 顧問 × 紫微研究者」：理解日常疲憊，能拆清問題，也坦白工具的來源與限制。文字應口語、真誠、精準，有生活細節與適度比喻。

| 穩定特質 | 文字中的表現 | 需要避免的偏移 | 來源依據 |
| --- | --- | --- | --- |
| 有人味 | 描述日常中的猶豫、疲憊與在意 | 空泛安慰、替人宣布感受 | B §10–12 |
| 有分析能力 | 說清楚可能在哪裡誤讀、如何核對 | 只剩漂亮散文或正確教養口令 | B §10、§13；P §7.2 |
| 方法坦白 | 直接說紫微斗數，區分詮釋與事實 | 神祕權威、科學包裝 | B §5；A §7.1 |
| 尊重主體 | 描述情境，保留不同意與改變 | 固定人格標籤、替孩子決定人生 | B §17；P §1.2 |
| 克制而有份量 | 以樣本、清楚內容與細節呈現價值 | 華麗口號、炫耀性奢華、低價快速量產訴求 | B §6；A §6 |
| 把關係還給當事人 | 結尾回到生活中的觀察與互動 | 長期陪伴承諾、對創辦人的情緒依附 | B §3、§6、§12.4 |

這些特質在各頁保持一致；正式程度、情緒濃度與技術深度可隨任務調整。

## 6. 網站文字的執行規範

**依據：B §11–16、§22–23；P §7；A §7–8。以下為執行轉譯。**

### 一段文字如何往前走

長文與介紹段可採：**具體場景 → 原有理解 → 另一種可能 → 如何核對 → 回到互動。** 不必每段都重複全套；按鈕、規格與流程文字優先清楚。

寫人時帶入情境與動作，例如「被連續追問時，他可能需要先停一下」，而不是「他天生封閉」。添加「可能」不能挽救沒有根據的判決；仍需留下其他原因及核對方式。

### 各頁語氣與任務

| 位置 | 正式程度／情緒／技術深度 | 主要任務 | 新擬句型示意 |
| --- | --- | --- | --- |
| 首頁 | 口語／溫暖克制／低 | 讓人辨認處境，知道品牌做什麼 | 「明明都很在意，怎麼還是聽不懂彼此？」接具體服務與方法說明 |
| 品牌故事 | 自然／可較深／中 | 連結創辦人經驗、生命觀與做法 | 「我想把那些急著下判斷的時刻，留一點空間給重新理解。」僅為語氣示意，個人經歷須另核實 |
| 報告頁 | 清楚／適度／中 | 說明單人範圍、內容、樣本與閱讀方式 | 「從一個人的命盤出發，整理可以帶回生活核對的理解線索。」 |
| 命書頁 | 細膩／溫暖／低至中 | 讓內容、心意與實體製作同時可見 | 「把此刻想理解他的心意，留在一本可以重新翻閱的書裡。」 |
| 諮詢頁 | 清楚／穩定／中 | 說明問題適配、九十分鐘與對談範圍 | 「從最近一次卡住的場景開始，談清楚這次想理解的一個問題。」 |
| FAQ／方法頁 | 直接／低／依問題深入 | 回答疑問，不迴避限制 | 「我們使用紫微斗數提供理解線索；與真實經驗不符時，解讀應被修正或放下。」 |
| 訂購／表單 | 簡明／低／必要即可 | 讓人知道要提供什麼、用途及下一步 | 「這本書主要寫給誰閱讀？」 |
| 文章／社群 | 口語／依場景調整／低至中 | 示範另一種觀看，不必篇篇導購 | 「那一次沉默，還可能有什麼原因？」 |

### 稱謂與編輯慣例（暫行）

- 全站使用繁體中文與臺灣常用語；品牌名固定「親紫之間」。
- 公共導覽、FAQ、流程暫用「你」或省略代名詞；明確寫給母親的文章可用「妳」。同一頁保持一致。原稿多用「妳」，全站政策尚待確認。
- 「我」用於已核實的 Jermaine 個人敘事；「親紫之間／我們」用於品牌與服務責任，避免暗示未確認的團隊規模。
- 每段處理一個意思；比喻後接生活或產品說明。避免一句同時塞入橡實、島、橋、航行與北極星。
- 標題可以有張力，但不能放大傷害或替人下結論。按鈕說明真實下一步，例如「閱讀報告樣本」「了解命書客製」「查看諮詢方式」；實際目的頁存在後才使用。
- 不把每個段落寫成免責聲明；方法與範圍放在讀者做決定的位置，關鍵限制仍須清楚可見。

## 7. 用詞與隱喻規範

**既定用詞，附執行說明｜來源：B §4–6、§14–15；P §2.6、§3.6。**

| 詞彙 | 用法與限制 |
| --- | --- |
| 紫微斗數、命盤、判讀 | 直接交代方法；不能換成模糊的「科學人格分析」 |
| 看見、認得、理解線索 | 指向具體經驗與可修正的理解，不暗示一次購買即可完全懂一個人 |
| 橡實、生命紋理、靈魂呼喚 | 用於故事或觀念深化；不是固定本質或購買前必須接受的信仰 |
| 北極星、座標、航行 | 用於定位與修正方向；不把 Jermaine 畫成唯一方向來源 |
| 島、橋、之間 | 指向兩個人的距離與互動；避免把讀者標成孤島 |
| 加入客製頁 | 對外描述命書選項；不以「解鎖」製造零碎付費感 |

避免用「天生就是」「注定」「孩子使用說明書」替人定型；避免改運、補運、劫難作為賣點；避免能量、頻率、宇宙訊息等另套體系；避免「大師、人生導師、燈塔」作為自我定位。

不以「我會一直陪妳」「有我在」「從此不再孤獨」承諾品牌依附。原始產品示例偶有「陪妳」用詞；本規範優先採「幫助」「一起核對」描述有範圍的工作，避免延伸成長期關係承諾。引用禁用語來解釋品牌邊界，不等同拿它作品牌主張。

## 8. 產品文案的準確邊界

**既定｜來源：P §2–8；B §8–9。**

| 產品 | 必須說清楚 | 不可擴張的承諾 |
| --- | --- | --- |
| 數位報告 | 一份描繪一人；父母版與孩子版閱讀視角不同；提供生活核對問題；可獨立閱讀成立 | 不含雙人比較、親子合盤或全家互動分析；不必購買諮詢才完整 |
| 禮物命書 | 承接單人報告，加入關係心意、編輯設計與實體製作；標準客製為第一頁與最後一頁 | 不只是 PDF 送印，也不是命理分析比較多；深度客製模組、頁數與工序未定案前不做具體交付承諾 |
| 諮詢 | 固定九十分鐘，以線上視訊為主；一次聚焦一個核心問題；相關命盤事前提交並確認適配 | 多張命盤不等於完整合盤，不逐張全盤解析；不保證一次解決問題，不承諾尚未定案的摘要、錄音或無限追問 |

「一對一諮詢」沿用品牌原有分類，視訊實際參與人數仍待定案，不能據此承諾夫妻或全家共同參與。諮詢不以先購買報告為前提。

品牌內容可以談父母、孩子與相碰的位置；這是觀看關係的架構，不代表單份商品同時交付三者分析。三項產品共享理念，不必平均分配頁面篇幅或資源。合盤尚屬未來產品，不當成現有功能銷售。

價格、交付天數、頁數、紙材、修改次數、開放名額、資料保存期限、優惠與取消規則，須由實際營運設定確認。不要補入推測數字，也不以來源中的規劃文字推定後台功能已完成。

命書需辨認命主、購買者與主要讀者。成年人出生資料及私人分析須有本人知情；未成年人由父母或合適法定照顧者提供資料。驚喜安排於心意與交付，不建立在未經同意的分析上。這裡沿用產品原則，具體資料政策另行制定。

## 9. 文案示範：如何改到品牌方向上

**以下全部為新擬示例，非成效案例；依據 B §5、§12–13、§17 與 P §2–4、§7。**

| 待改文字 | 問題 | 可採用的改寫方向 |
| --- | --- | --- |
| 「精準解碼孩子，掌握他的未來。」 | 把人當固定答案，暗示預測能力 | 「從命盤提供的線索出發，重新觀察眼前的孩子。」 |
| 「他天生固執，所以你要換一套教法。」 | 人格判決，加上命令式教養 | 「臨時改變安排時，他是不是特別難接受？先看看他在意的是什麼，再聽聽他的說法。」 |
| 「再不理解他，就來不及了。」 | 製造恐懼 | 「有沒有一個反覆發生的時刻，讓你想重新理解他的反應？」 |
| 「讀完報告，親子關係從此改善。」 | 把方向寫成效果保證 | 「報告整理理解線索與觀察問題，讓你帶回日常，看看哪些貼近、哪些需要修正。」 |
| 「我會一直陪你，成為你的北極星。」 | 製造品牌依附 | 「在這次對談裡，一起釐清問題，找出下一次可以觀察與嘗試的方向。」 |
| 「一份命書，看懂你們全家的互動。」 | 超出單人產品範圍 | 「以一個人的生命報告為基礎，加入你想留下的記憶與心意。」 |

### 一段完整的場景示範

> 你問他今天過得怎麼樣，他只回了一句「還好」。你再問，他就不說了。你可能以為他不想理你；也有可能，他還沒整理好要怎麼說。先把這個可能留著，換個時刻聽聽他的回答。如果他說原因不是這樣，就讓他的說法改變你的理解。

這段示範讓日常細節承接觀點，提出可推翻的理解，最後回到孩子的回應。它不宣稱沉默必然代表某種需要，也沒有建立星曜與行為的固定對應。

### 品牌介紹示範

> 親紫之間用紫微斗數命盤提供理解自己與孩子的線索。我們把這些線索寫成可以閱讀的報告、可以保存心意的命書，也透過諮詢，讓具體生活經驗參與判讀。哪些貼近、哪些不同，都值得重新核對。我們希望這份理解能回到生活，讓父母與孩子多一次聽懂彼此的機會。

此段表達品牌層次；各產品頁仍須加上單人範圍或對談範圍。上述文字可供未來改寫，不代表已選定首頁主標。

## 10. 設計建議的品牌依據

**延伸建議｜依據 B §6、§10、§14、§17；P §3；A §6–8。原資料未提供正式色票、字體或視覺識別規範。**

設計應讓人感到文字值得細讀、方法容易理解、人物受到尊重，並能清楚選擇適合自己的產品。

| 品牌內涵 | 可以採取的設計方向 | 評閱問題 |
| --- | --- | --- |
| 有人味與生活感 | 使用有具體互動的日常影像、插畫或文字場景 | 看得到人的處境，還是只有抽象星空？ |
| 顧問的清楚 | 建立閱讀層次，讓方法、樣本與產品範圍容易找到 | 讀者能說出這項產品做什麼嗎？ |
| 有份量與審美 | 以排版、留白、材質細節與真實內頁呈現品質 | 美感是否支持閱讀與產品內容？ |
| 孩子的主體性 | 保留人物各自的位置與表達，避免被操控的圖像語言 | 孩子像有自己生活的人嗎？ |
| 定位與修正 | 星點、座標、航行元素可少量使用 | 隱喻幫助理解，還是暗示命運已被安排？ |
| 方法誠實 | 關鍵說明放在正常閱讀層級 | 是否用小字或折疊隱藏方法與限制？ |

可探索溫和底色、清楚的文字對比與少量紫色識別，但不因品牌有「紫」就規定全站紫色，也不把黑金星盤當預設。字體、色碼、字級與動態需另依實際頁面測試；不能把低對比、過小字或過度動畫當成細膩。

命書視覺應同時呈現內容與物件；示意圖須標明示意，不把未生產的紙材、裝訂或包裝當成現貨證據。三項服務都應可找到，不需要為了「三軌等重」犧牲資訊層次。

## 11. 網站文字審核方式

**執行規範｜依據 B §19、§23–24；P §9；A §8。**

每次檢視先確認頁面目的與讀者，再按下列順序判斷：人的尊嚴 → 品牌核心 → 品牌姿態 → 方法誠實 → 產品與商業 → 單次創意。

- [ ] 讀者能辨認具體處境，或清楚知道這一頁要提供什麼資訊。
- [ ] 命盤被表達為可核對的詮釋，沒有冒充科學、診斷或固定本質。
- [ ] 父母與孩子都有尊嚴；孩子可以不同意，理解也不取消界線。
- [ ] 沒有新造恐懼、羞辱父母、預言災禍或承諾必然改善。
- [ ] 語氣符合父親、顧問與紫微研究者，沒有變成大師或情緒陪伴者。
- [ ] 文案最終連回生活與親子互動，沒有讓品牌成為依賴中心。
- [ ] 單人報告、命書、諮詢與未來合盤的範圍沒有混淆。
- [ ] 數字、規格、案例、資歷與製作流程有可核對依據；沒有拿假設當事實。
- [ ] 比喻有助理解，且有具體內容承接；按鈕與流程清楚。
- [ ] 孩子日後讀到這段話，仍能感到被尊重，而非從出生就被判決。

審核結果分三種：**必須修正**（違反核心、方法或產品事實）、**建議調整**（空泛、語氣偏移、資訊不清）、**可保留**（符合目的與品牌）。核心問題不能用總分或其他優點抵銷。

回報格式：`頁面／區塊｜原文｜判定｜問題與來源章節｜建議改寫｜待確認事實`。不要只說「不夠有品牌感」，要指出具體字句及其造成的期待。

## 12. 後續協作與更新

開始新文案時，先使用現有資訊確定：頁面位置、主要讀者、要完成的溝通任務、相關產品、可用事實與字數限制。缺少非必要資訊時採合理暫案並註明；缺少價格、交付承諾等重要事實時，不自行編造。

提出設計建議時，說明「對應哪個品牌原則、解決哪個閱讀或選擇問題、哪些屬待測試方案」。品牌內涵不等於每個畫面都要出現星星、橡實或紫色。

後續確認的新設定，記入本文件版本紀錄；涉及核心或產品範圍的修改，也同步更新對應來源，避免兩套規範。未明確要求重新定位時，維持既定品牌核心。
