## 1. 文件定位與資料可信度

本文件回答：親紫之間希望讓誰認出自己的處境？他們為什麼閱讀、留下、購買或推薦？不同取用方式如何幫助父母重新看見孩子？

這是一份可獨立閱讀的專案資料，不是 skill、工具指令或自動執行流程。不依賴 persona-library，也不假設專案已有原稿提到的旅程、定位或內容支柱文件。

品牌底層決定方向與倫理；本文件提供受眾理解；產品、定價、渠道與文案再依此發展。受眾偏好不能覆蓋品牌原則。

## 2. 核心受眾與真正需求

### 2.1 核心受眾

**品牌既定：**30–45 歲、有一定教育程度與美學要求，讀過不少教養內容，但對主流教養工具逐漸疲憊的母親與文藝型父母。

這是溝通重心，不是服務資格。年齡、學歷、性別或職業都不足以判定一個人是否需要品牌；也不應直接推算其收入、預算或付費意願。家庭可處於幼兒、學齡、青春期或成年子女階段，但各階段需求仍須分別驗證。

更有辨識力的共同處境是：

- 已經努力理解孩子，也接觸過教養知識，仍在某些相同場景反覆卡住。
- 不想只得到「妳應該怎麼做」，希望有人把誤讀發生的位置說清楚。
- 願意考慮紫微斗數提供的另一種觀看方式，但接受程度不同。
- 重視被尊重、內容深度與方法坦白，不希望自己或孩子被判決。

### 2.2 需求的三層

| 層次 | 讀者可能帶來的問題 | 品牌應回應的方向 |
| --- | --- | --- |
| 表面問題 | 「為什麼每次講到這裡就吵起來？」 | 描出具體相撞場景，讓讀者辨認是否與自己有關 |
| 理解需求 | 「我已經很努力，怎麼還是看不懂他？」 | 看見父母與孩子各自在意、保護與誤讀的地方 |
| 關係期待 | 「我希望他知道，我有努力理解他。」 | 讓理解回到真實互動，增加一次看見孩子的可能 |

「恐懼是入口、孤獨是病、認得是藥」是品牌的內部比喻，不是對每位讀者的心理診斷。也有人出於好奇、欣賞、收藏或送禮而來，不必替他們補上一份焦慮。

### 2.3 閱讀後希望發生的變化

讀者能帶走的，不只是更多人格描述，而是認出一個具體場景，理解自己原本的解讀可能不完整，願意回到孩子的反應與說法重新觀察。

這是產品與內容的方向，不是保證親子衝突消失的效果承諾。

## 3. 讀者、買家、使用者與推薦者

原稿偏重「誰會買哪種產品」。作為讀者底層，必須把角色拆開，避免把所有閱讀都解讀為購買前奏。

| 角色 | 主要問題 | 對內容或產品的期待 |
| --- | --- | --- |
| 內容讀者 | 這是否說中了我家的某個時刻？ | 具體場景、清楚論述、值得帶回生活的觀看角度 |
| 自用買家／父母使用者 | 付費後能比免費文章多理解什麼？ | 個別化描繪、人的閱讀與判斷、交付範圍明確 |
| 送禮買家 | 對方會喜歡嗎？會不會感覺被冒犯？ | 心意、裝幀、內容樣本、收禮者接受度與製作流程 |
| 收禮者／未來閱讀的孩子 | 這本書怎麼描述我或我的孩子？ | 尊重、開放性、可重新閱讀，也能不同意其中的描述 |
| 諮詢預約者 | 這次具體問題適合拿來談嗎？ | 清楚範圍、對話深度、把命盤帶回真實關係 |
| 推薦者 | 我是否了解產品，足以介紹給合適的人？ | 親身經驗或可檢視的樣本，不被要求為未用過的產品背書 |

同一個人可同時擔任多個角色，也可閱讀很久而不購買。推薦者的人脈不等於已存在的市場需求。

## 4. 四位人物參照

四位都來自創辦人的既有關係網絡，適合協助提問與初期校準，尚不足以代表市場分群。以下不是固定人格分類；實際對話與行為優先於畫像。

### 4.1 Julian｜先確認相關性與說明是否清楚

**原稿觀察：**創辦人的配偶，從事數據分析，有幼兒階段孩子；務實、問題導向，會先判斷內容是否與自己有關，對命理開放但不是剛需。年齡與家庭階段為原稿快照，不推算為目前精確狀況。

**閱讀需求（工作假設）：**她想知道這段話如何連回眼前的孩子，以及讀完能多看見什麼。可以接受詩意，但需要場景、說明與適用邊界來承接。

**示意心聲：**「我知道要尊重他，但每次出門都卡住。這個角度能幫我多看懂哪一點？」

**信任線索：**具體的內容樣本；坦白使用紫微斗數；解釋判讀如何形成，並允許讀者指出不符合之處。

**可能障礙：**只有漂亮結論、沒有生活連結；把命盤說成孩子本質的證明；無法說清楚交付內容。

| 接觸方式 | 工作假設 |
| --- | --- |
| 數位報告 | 優先驗證的自用客群；較容易評估，但不代表必須低價 |
| 禮物命書 | 自用意願可能較低；送禮取決於對方接受度 |
| 諮詢 | 可能在具體問題出現、看過內容後考慮；不推定必然預約 |
| 推薦／電子報 | 可能在朋友主動詢問時介紹；訂閱與開信仍待驗證 |

**對專案的用途：**檢查一般文章與報告頁是否回答「跟我有什麼關係」「如何理解這個說法」「能帶回哪個生活場景」。她是優先參照之一，不是所有文章唯一的讀者。

### 4.2 KiKi｜帶著具體問題，重視對話判斷

**原稿觀察：**創辦人的長期熟人，科技業 PM，有接近或進入青春期的孩子；重視孩子主體與判斷品質，對 Jermaine 的信任高於對命理工具的興趣。原稿將她描述為已有諮詢關係的參照。

**閱讀需求（工作假設）：**她關心能否把複雜的親子問題拆清楚，不一定需要長篇概念介紹。內容應呈現如何理解問題，而不只展示解盤結論。

**示意心聲：**「我不想替他決定，但也擔心自己漏看了什麼。這個問題可以怎麼拆開？」

**信任線索：**提問品質、對具體情境的理解、服務範圍與交付清楚。熟人信任是此樣本的特殊條件，不能假設陌生客戶也具備。

**可能障礙：**空泛共感、替家庭下決定、把「找你聊」發展成持續依賴。

| 接觸方式 | 工作假設 |
| --- | --- |
| 數位報告 | 可能作為閱讀或對話參照，但優先順序待驗證 |
| 禮物命書 | 可能有合適的推薦對象；孩子年齡不能作為她不會自用購買的理由 |
| 諮詢 | 最接近現有服務經驗的參照；不據此推算頻率、價格天花板或續約 |
| 推薦／電子報 | 可能偏好直接詢問；不能寫成一定不訂閱，或保證高轉換 |

**對專案的用途：**檢查諮詢是否能處理真實問題，以及陌生人如何在沒有私人交情時判斷服務品質。回訪可以基於新問題，不以「離不開 Jermaine」作為成功指標。

### 4.3 Polly｜欣賞深度與美感，也會檢查論述

**原稿觀察：**來自創辦人熟人網絡，曾任育兒媒體編輯，有多名幼兒至學齡階段孩子；具占星閱讀背景與美學要求，原稿描述她較偏向興趣與滿足驅動。

**閱讀需求（工作假設）：**希望內容承受得起細讀，能描繪一種特質在不同關係中的多面性；不需要每篇都以焦慮吸引她。

**示意心聲：**「我喜歡這個比喻，但它有沒有真的打開理解，還是只是把孩子換一種方式分類？」

**信任線索：**細緻論述、完整樣本、設計與內容一致、容納不符合的經驗。命理素養可幫助她評估論述，但不是方法有效性的驗證。

**可能障礙：**漂亮卻空泛、神祕權威、宿命論，或把「允許孩子」說成沒有界線與責任。

| 接觸方式 | 工作假設 |
| --- | --- |
| 數位報告 | 有機會先用一份評估內容；多名孩子不等於會買多份 |
| 禮物命書 | 美感、收藏與重讀價值可能成立；仍需確認價格與實際需求 |
| 諮詢 | 可能為具體議題尋求深談；頻率、金額與題目不視為既定 |
| 推薦／電子報 | 可能因合適情境推薦或持續觀察品牌，待實際行為驗證 |

**對專案的用途：**作為早期內容與設計評閱者之一。她的回饋有價值，但不代表整個「高知客群」的接受門檻，也不能取代不熟悉創辦人的讀者測試。

### 4.4 Kao｜周邊讀者與服務邊界參照

**原稿觀察：**創辦人的前同事，曾從事數位行銷，現為自由工作者；可能透過既有人際連結接觸內容，命理接受度不明。原稿另載家庭特殊發展相關資訊，且「傾向診斷／已有診斷」表述不一致，本文件不將它固化為醫療事實。

**閱讀需求（工作假設）：**可能先因認識作者而閱讀；是否關心產品、會不會推薦，目前資料不足。

**信任線索：**尊重真實經驗，不拿家庭處境做推銷素材，也不讓命盤凌駕既有專業評估。

**對專案的用途：**保留為周邊接觸者參照，不列為積極開發樣本；同時提醒服務應依「提出的需求」判斷是否適合，不能因孩子的診斷或發展差異排除整個家庭。

品牌不提供以命盤診斷、排除或驗證自閉症、ADHD 等議題的服務。若需求是日常親子理解，也不能只加一句免責聲明就視為可承接；仍須確認討論範圍在品牌能力內，且不把發展差異歸因於命格。這是品牌服務範圍，不是醫療建議。

不以「投入優先級零」或「擴散價值極弱」描述這個人的價值；商業投入判斷與對人的尊重分開。

## 5. 尚未取得真人樣本的送禮者

**工作假設，非第五位已驗證 persona。**

送禮者可能是親友、祖父母或另一位家長；重點是「買給哪個家庭、由誰閱讀、對方願不願意收到」，不是某個固定身分。

其評估可能包括：物件是否有份量、心意能否被理解、內容是否尊重孩子、是否引起收禮者對命理的反感、出生資料如何由合適的人提供，以及交付時間是否符合場合。

**示意心聲：**「我想送一份能留下來的禮物，但不希望對方覺得我在替孩子決定他是誰。」

送禮頁可先呈現物件與心意，再讓人看清內容、方法與流程；不能只談裝幀而隱藏紫微斗數，也不能假定送禮者不在乎內容。

訂單分類應詢問「自用或送禮、與孩子的關係、主要閱讀者」，不能用「訂購人不等於孩子」判斷送禮，因為父母自用訂購通常也符合這個條件。

## 6. 三種取用方式的共同核心與差異

**品牌既定：**數位報告、禮物命書、一對一諮詢共享同一份生命描繪與品牌哲學。

「共同核心」不等於逐字相同或交付範圍完全一致。諮詢有互動，實體書有物件意義，數位報告需要適合獨立閱讀。

| 形式 | 主要取用心智 | 優先驗證的受眾 | 需要看清的價值 |
| --- | --- | --- | --- |
| 數位報告 | 我想先了解，數位閱讀即可 | Julian、Polly 所代表的需求 | 個別化程度、可讀性、人的閱讀與判斷、與免費內容的差異 |
| 禮物命書 | 我想收藏或送一份能留下的心意 | Polly、尚待訪談的送禮者與收禮者 | 內容與物件共同成立，能經得起孩子未來閱讀 |
| 一對一諮詢 | 我有一個具體問題，想直接談 | KiKi，以及尚待取得的陌生預約者 | 如何把判讀連回人物、事件與關係；範圍與限制 |

原稿「三軌等重」保留為可測試的商業主張，不升格為固定品牌原則。三者都可被清楚找到，不代表版面、資源或營收必須平均。

不綁單一年齡，不等於年齡與場景無關。幼兒家長的轉換情境、學齡家庭的生活摩擦、青春期的界線與成年子女的距離，都應以不同實際經驗核對，不能只改稱謂。

## 7. 共通溝通原則

### 7.1 靈魂呼喚：說明詮釋過程，保留理解的空間

「靈魂呼喚」與「橡實」保留為品牌生命觀與敘事語言。不同讀者可能需要不同程度的概念說明，不能因理性、命理素養或熟人關係就預先認定對方接受。

方法說明可交代出生資料如何用於排盤、採取什麼命盤判讀，再說明如何形成敘事；不能把「出生時間 → 主星 → 靈魂呼喚」寫成已證明孩子本質的因果鏈，也不把一顆主星當成一個人的全部。

解釋更清楚，可能增加可理解性；不等於對方必然認同。命盤描述始終要回到生活觀察，讓父母與孩子有不同意與修正理解的空間。

### 7.2 真正被人看過：品質要可見，流程要誠實

原稿對「真人 vs AI」的負面反應僅列為未驗證假設，不採用「絕對不能明示」的鐵律。

品牌可透過樣本、細緻程度與交付流程呈現人的介入；被問及製作方式時，如實說明 AI 參與與人的責任。是否把它作為廣告主題可測試，資訊誠實不能因預想的受眾品味而取消。

### 7.3 具體場景優先，讓橋回到親子之間

一般文章可從讀者熟悉的摩擦、困惑或欣賞出發，再展開另一種理解。談父母、談孩子，也談兩者相碰的位置；不要把內容縮成孩子的人格清單。

對外不稱讀者為「高知理性媽媽」「資訊焦慮型」「推薦節點」。不把熟人的信任寫成品牌效果保證，也不讓文案最後停在對 Jermaine 的依賴。

| 真正送禮者與收禮者 | 推薦者不能代表買家，也不能代表收禮感受 | 分別詢問選禮、接受度、使用與資料提供意願 |
| 非熟人的諮詢預約者 | KiKi 的關係基礎不能直接複製 | 記錄來談的問題、預期、選擇理由與談後回饋 |
| 不同孩子階段及父親／其他照顧者 | 目前人物集中於熟人母親，成年子女情境尤其不足 | 依實際來源逐步累積，不先宣稱已覆蓋 |
| 未購買、取消或不滿意者 | 只看成交者會漏掉阻礙與服務落差 | 記錄原因，不把所有拒絕歸為不懂品牌 |
| 電子報讀者 | 訂閱、閱讀、信任、購買是不同動作 | 綜合回覆、點擊、退訂與購買；不以單一開信數字判定動機 |

原稿提議的前 5–10 位預約者、10–20 位買家，可作為初期質性盤點節點，不能當成統計代表性或證明某類型成立的門檻。

### 9.2 每筆觀察可保留的欄位

日期、來源與是否熟人、匿名代號、角色、家庭階段概況、觸發場景、本人原話、實際行為、分析者解讀、反例、可使用範圍。

原話與推論分開記錄；只保留分析需要的個人資訊，不將孩子診斷細節放進共用畫像。對外引用須另有適當授權，不能把本文件的示意心聲當作見證。

新資料出現時，更新特定假設的支持程度、範圍與反例，不把單次符合改寫成「所有這類人都會如此」。

### 9.3 尚未確立的營運設定

- 每月諮詢上限五場、熟人優先資格：原稿方案，需依真實產能與公平的預約設計決定。
- 高頻諮詢、每年一至兩次、三個孩子買三份、高轉換推薦：皆非已確認行為。
- 三軌等重、報告低門檻、特定年齡優先開發：可變策略，不是品牌底層。
- 成人轉職、伴侶關係、移民、大限主題：原稿列出的延伸需求，尚不能視為已上架服務；先確認是否符合本品牌親子核心與承接能力。
- 「五萬樣本」：原稿出現但沒有定義、來源或可核對依據，本文件不將其列為實力證據或對外宣稱。

## 11. 專案快速參照

親紫之間優先理解那些已經努力教養、仍在某些地方看不懂孩子的父母，也容納出於欣賞、好奇與送禮而來的人。

Julian 幫助檢查相關性與說明；KiKi 幫助檢查具體對話的價值；Polly 幫助檢查深度與美感；Kao 提醒周邊讀者與人的尊嚴不能被商業分類簡化。四人都是理解需求的參照，不能代替真正的市場樣本。

最終判準仍是：**這份理解，有沒有讓父母更有可能真正看見孩子，而沒有以恐懼、權威、定型或依附作為代價？**
